# Nomie Intention v2

Set one intention for the day, see it on the dashboard, and mark it as kept in the evening. Both go into your timeline (`#intention` and `#intention_kept`), in the app's colours.

Source: https://github.com/RdeLange/nomie-intention-v2. Pages: https://dailynomie.github.io/nomie-intention-v2/

## Commands

    npm install
    npm test
    npm run build

The build goes to `dist/`, ready for GitHub Pages. In Nomie, add the plugin by the URL of the Pages site.
